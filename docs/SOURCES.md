# Primary references checked during implementation

- [Angular release policy](https://angular.dev/reference/releases), [runtime compatibility](https://angular.dev/reference/versions) and npm registry metadata for Angular core/CLI/build. Stable versions selected on 31 October 2026: core 22.2.4, CLI/build 22.2.5; compatible TypeScript 6.
- [Tailwind Angular integration](https://tailwindcss.com/docs/installation/framework-guides/angular): Tailwind 4 PostCSS integration.
- [springdoc compatibility matrix](https://springdoc.org/v2/): Spring Boot 3.5 with springdoc 2.8.x; Maven Central release metadata confirmed exact versions.
- [GitHub Actions checkout](https://github.com/actions/checkout/releases), [setup-node](https://github.com/actions/setup-node/releases), [setup-java](https://github.com/actions/setup-java/releases), [upload-artifact](https://github.com/actions/upload-artifact/releases). Public GitHub release/tag metadata supplies pinned commit hashes in CI.
- [Ministry of Finance, circulation-tax services](https://www.finances.gov.tn/fr/autres-services): linked in the guide without reproducing potentially changing rates.
- [Douane, retour définitif](https://www.douane.gov.tn/retour-definitif/) and [ATTT](https://www.attt.com.tn/): official destinations for situation-specific confirmation. These two sites timed out or returned an error during the reference check, so no current eligibility, deadlines or prices are asserted by CarNova.
- Embedded GLB metadata supplies the ToyCar CC0 and Datsun CC BY-SA attribution, reproduced on the studio and about pages. No newly scraped image assets are used.
