# CarNova frontend

Angular 22 standalone SPA with signals, typed reactive forms, Tailwind 4, deferred Three.js and a French-first marketplace design.

See the [root README](../README.md) for the complete Compose stack, configuration, screenshots, architecture and verification. Run `npm ci && npm start` for local development against a backend on port 8081. Run `npm test`, `npm run build` and `npm run test:e2e` for verification.
