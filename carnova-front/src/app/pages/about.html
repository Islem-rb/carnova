Projet, données & crédits.

CarNova v2 est un projet de portfolio. Dans l’environnement de démonstration, les véhicules de présentation ne sont pas des offres réelles. Les annonces créées par les utilisateurs restent sous leur responsabilité. Aucun paiement réel n’est proposé : le parcours de paiement utilise une simulation locale ou Stripe TEST.

Vos données dans cette plateforme.

Le compte enregistre vos nom, prénom, e-mail et un mot de passe haché. Les annonces et showrooms affichent votre nom de vendeur et les coordonnées de contact que vous choisissez d’y publier. Votre e-mail de compte et votre mot de passe ne figurent pas dans les annonces publiques.

Les favoris et le choix du thème restent dans le stockage de votre navigateur. La session de connexion reste dans l’onglet et expire automatiquement. Les messages de contact sont enregistrés dans la boîte de réception administrateur. La conversation avec le guide hors ligne est temporaire ; si l’exploitant active Ollama, vos questions sont traitées par son serveur local.

Pour une question concernant vos données, utilisez le formulaire de contact. Les propriétaires d’une installation doivent définir leurs propres coordonnées, durées de conservation et règles avant une exploitation publique.
